# create-antd-layout

This is a CLI that uses "@adminui-dev/antd-layout" to quickly build web projects

## There are a total of 3 sets of templates
- `simple` - Minimized basic template
- `max` - Basic interactive pages that support internationalization and custom components
- `pro` - Equipped with custom theme skins and comprehensive interactive features

## Usage
```bash
npx create-antd-layout project-name
```
